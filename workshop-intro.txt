📖 简介

MeiChat 是一个 VPet（虚拟桌宠模拟器）插件，将 DeepSeek AI（兼容 OpenAI 格式）接入桌宠。
以崩坏三主角雷电芽衣的形象，为你带来集 AI 对话、代码阅读、文件管理、命令执行为一体的
智能桌面助手体验。

✨ 两大模式

💬 聊天模式
  与芽衣自由对话，支持 15+ 种模型预设（DeepSeek / OpenAI / Claude / Gemini / 通义千问 /
  GLM-4 / Moonshot / 文心 / SiliconFlow 等），也可手动输入任意模型名。

🤖 Agent 智能体模式
  芽衣不只是聊天——她能像编程助手一样自主工作：
  · 📖 阅读项目代码，理解项目结构
  · ✏️ 创建、编辑、修改文件
  · 🔍 全局搜索代码关键词
  · 🖥️ 执行 Shell 命令（编译、运行、Git 操作）
  · 🔄 自主规划步骤，多轮推理直到任务完成

  输入 /agent 即可激活，适合代码开发、项目管理、文档编写等场景。

🛡️ 安全可控

  · 命令执行弹窗确认，防止误操作
  · 可开启自动模式（/auto），常规操作静默执行
  · 删除 / 危险操作仍需确认，双重保障
  · 支持自定义工作目录，限定文件操作范围

🛠️ 功能特色

  ✅ 原生 TalkBox 集成 - 桌宠气泡直接对话
  ✅ 流式响应 - 实时看到回复逐字出现
  ✅ 完全自定义系统提示词 - 打造属于你的芽衣
  ✅ 温度 / Max Tokens 可调 - 控制 AI 输出风格
  ✅ 可切换 15+ 种模型预设
  ✅ 支持自定义 API 地址（兼容任何 OpenAI 格式 API）
  ✅ 文件管理 - 安全工作目录操作
  ✅ 一键更新 - 新版本自动同步

📋 使用方法

  1. 安装本 Mod 后启动 VPet
  2. 右键桌宠 → 系统 → 设置 → Mod/插件管理
  3. 找到 MeiChat，点击设置齿轮 ⚙️
  4. 填入你的 API Key（DeepSeek / OpenAI / Anthropic 等）
  5. 选择模型，保存设置
  6. 在聊天框输入消息开始对话！

💡 快捷指令

  /agent   🤖 开启 / 关闭 Agent 智能体模式
  /auto    🔄 切换自动执行模式
  /chat    💬 返回普通聊天模式
  /clear   🗑️ 清空对话历史
  /help    📋 显示帮助
